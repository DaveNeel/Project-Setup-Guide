This repository contains rules, contracts, and an intake engine for scaffolding backend projects.

## Instructions
1. Always start by reading [AGENTS.md](file:///c:/Users/neel2/OneDrive/Desktop/Practise/project-setup/AGENTS.md).
2. Follow the 11-step pipeline defined in [intake/step-wise-intake.md](file:///c:/Users/neel2/OneDrive/Desktop/Practise/project-setup/intake/step-wise-intake.md).
3. Validate answers against [intake/decision-tree.md](file:///c:/Users/neel2/OneDrive/Desktop/Practise/project-setup/intake/decision-tree.md) and [intake/compatibility-matrix.md](file:///c:/Users/neel2/OneDrive/Desktop/Practise/project-setup/intake/compatibility-matrix.md).
4. Load only the specific standards selected via the Routing Table in `AGENTS.md`.
5. Obtain human approval for your generation plan before writing code into the target external directory.
6. Verify the generated project passes `npm run build` and `npm run lint`.
